# Application Log Source Design

## 1. Purpose

Application logs will represent operational logs generated by the logistics applications.

These logs will help the engineering team understand:

- Application failures
- API failures
- Pipeline-related issues
- Processing problems
- Operational events
- Service performance

---

# 2. Source System

Source:

Logistics Application Platform

Format:

JSON

Processing Type:

Near real-time / Batch

---

# 3. Log Structure

Each log event will contain:

```text
log_id
event_timestamp
service
environment
log_level
message
correlation_id
