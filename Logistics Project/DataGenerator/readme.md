# Logistics Data Generator

## Purpose
Generates realistic logistics data for the Real-Time Logistics & Delivery Analytics Platform.

## Features
- Generates 10,000+ records across 7 tables
- Injects realistic data quality issues (nulls, duplicates, outliers)
- Simulates real-world business rules
- Configurable data volumes
- Batch insertion for performance
